= すべてのプログラミング言語のチュートリアル

すべてのプログラミング言語のチュートリアルを目指すリポジトリ。

いきなり全部を同じ深さでは書かず、3段階で育てています。

* *Tier C（紹介）:* 全言語を1ページで紹介する（言語一覧が土台）
* *Tier B（ミニ）:* Hello World＋変数・制御構文・関数までの共通章
* *Tier A（しっかり）:* コレクション・エラー処理・小プロジェクトまで

章立ては全言語共通です（xref:template.adoc[テンプレート]）。
仕上げ課題も全言語でそろえています（FizzBuzz → 数当て → 簡易ToDo）。
