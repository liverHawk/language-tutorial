= テンプレート（各言語ページの型）

各言語のページ（`docs/modules/ROOT/pages/<言語>.adoc`）は、この形で書きます。
本文は AsciiDoc です。サイト（Antora）と EPUB の両方にそのまま使われます。

[source,asciidoc]
----
= {言語名} チュートリアル

- 得意なこと: {一言}
- 公式サイト: {URL}
- 難易度目安: ★{1〜5}（公式評価ではなく、入りやすさの目安）

== 0. この言語について
{何のために作られ、今どこで使われているかを3〜5行で}

== 1. Hello World と実行方法
{インストール／実行方法を最短で}
{Hello World のコード}

== 2. 変数と型
{コード例1つ＋説明3行以内}

== 3. 条件分岐と繰り返し
{if と for/while の最小例}

== 4. 関数
{定義と呼び出しの最小例}

== 5. コレクション
{リスト／配列と辞書／マップ相当}

== 6. エラー処理
{例外またはエラー値の扱い}

== 7. 仕上げ: FizzBuzz
{全言語共通課題。次は数当て → 簡易ToDo}

== 次に読むもの
{公式チュートリアル等へのリンク2〜3個}
----

コードは「言語の標準的な書き方」で統一し、このチュートリアル自体の実行確認は
`examples/` ではなく各言語の公式プレイグラウンド等へのリンクで代替します。
完全なサンプルとして Python と JavaScript のページが最後まで書いてあります。
